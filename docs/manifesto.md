# Манифест Synapse

Мы верим, что:

1. **Каждый человек носит в себе идеи, которые могут изменить мир.**
2. **Идеи редко реализуются в одиночку — нужны связи.**
3. **Современные платформы не умеют автоматически связывать людей по их глубинным потребностям.**
4. **ИИ может стать мостом между людьми, а не заменой им.**

**Synapse** — это попытка создать такой мост.

---

## Наши ценности

- **Открытость** — код открыт, алгоритмы прозрачны.
- **Приватность** — данные принадлежат пользователю.
- **Свобода** — вы выбираете, с кем связываться.
- **Польза** — мы помогаем людям реализовывать идеи.
