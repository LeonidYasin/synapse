# Как участвовать в Synapse

Мы рады каждому, кто разделяет наши ценности: **открытость, приватность, полезность**.

## Принципы участия

1. **Будь уважителен** — мы строим сообщество, а не токсичный балаган.
2. **Предлагай, а не критикуй** — если видишь проблему, предложи решение.
3. **Пиши код, который понятен другим** — комментарии, тесты, документация.
4. **Не бойся ошибаться** — мы учимся вместе.

## Как внести вклад

### 1. Найди задачу
- Зайди в раздел [Issues](https://github.com/LeonidYasin/synapse/issues).
- Выбери задачу с меткой `good first issue`, если ты новичок.
- Или предложи свою задачу, если видишь, что можно улучшить.

### 2. Форкни и создай ветку
```bash
git clone https://github.com/LeonidYasin/synapse.git
cd synapse
git checkout -b feature/your-feature-name
```

### 3. Пиши код
- Следуй стилю кода.
- Пиши тесты.
- Добавляй комментарии.

### 4. Сделай Pull Request
- Опиши, что ты сделал и зачем.
- Ссылайся на соответствующий Issue.
- Дождись ревью.

## Как предложить идею
Открой [Discussion](https://github.com/LeonidYasin/synapse/discussions) или напиши в Telegram-канал.

## Кодекс поведения
Мы придерживаемся [Contributor Covenant](https://www.contributor-covenant.org/).
