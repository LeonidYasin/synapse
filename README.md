# Synapse — социальная сеть на основе ИИ-чатов

**Связываем людей через идеи, потребности и возможности.**

---

## Что это?

Synapse — это открытая платформа, где вы можете:

1. **Общаться с любыми LLM** (Claude, GPT, DeepSeek, локальные модели).
2. **Высказывать идеи, задавать вопросы, искать помощь.**
3. **Агент ИИ анализирует все диалоги** (с вашего согласия) и находит:
   - Людей со схожими интересами.
   - Инвесторов для ваших идей.
   - Экспертов, которые могут помочь.
   - Партнёров для совместных проектов.
4. **Связываться** с подходящими людьми автоматически или по запросу.

## Принципы

1. **Приватность по умолчанию** — диалоги сканируются только с явного согласия.
2. **Анонимность** — вы можете оставаться анонимным до момента связи.
3. **Открытый код** — всё прозрачно, любой может запустить свою версию.
4. **Децентрализованное управление** — в будущем DAO.
5. **Свобода выбора LLM** — вы сами выбираете модель для общения.

## Технологии (планируемые)

| Компонент | Технология |
|-----------|------------|
| Фронтенд | React / Next.js (или чистый HTML) |
| Бэкенд | Python (FastAPI) / Node.js |
| База данных | PostgreSQL + Elasticsearch |
| Агент | Python + LangChain / LlamaIndex |
| LLM | API Claude, GPT, DeepSeek, локальные |
| Очереди | Redis / Celery |
| Контейнеризация | Docker / Kubernetes |
