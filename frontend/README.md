# Synapse Frontend

Минимальный прототип интерфейса Synapse.

## Запуск

1. Открой `index.html` в браузере.
2. Начни общаться с ИИ.
3. Агент автоматически анализирует диалоги и предлагает связи.

## Структура

- `index.html` — главная страница
- `css/styles.css` — стили
- `js/` — JavaScript-модули
  - `app.js` — точка входа
  - `chat.js` — логика чата
  - `agent.js` — ИИ-агент (имитация)
  - `matches.js` — рекомендации
  - `auth.js` — авторизация
