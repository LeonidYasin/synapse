# Synapse Extension — связи через диалоги

Браузерное расширение, которое анализирует ваши диалоги с ИИ и находит связи с другими людьми по интересам, идеям и потребностям.

## Установка

### Вручную (для разработки)
1. Скачайте или клонируйте репозиторий
2. Откройте Chrome → `chrome://extensions/`
3. Включите "Режим разработчика"
4. Нажмите "Загрузить распакованное расширение"
5. Выберите папку `synapse-extension`

## Использование

1. Откройте любой чат с ИИ (DeepSeek, ChatGPT, Claude)
2. Нажмите кнопку 🧠 в правом нижнем углу
3. Нажмите "Анализировать диалог"
4. Получите рекомендации по связям
